# 표준 절차서 포털 (오프라인 / 폐쇄망용 정적 HTML)

서버 없이 **브라우저에서 바로 열리는** 절차서 열람 포털입니다.
인터넷 연결 없이(폐쇄망), 압축 파일을 풀고 `index.html` 을 더블클릭하면 동작합니다.

## 화면 구성

| 파일 | 설명 |
|---|---|
| `index.html` | **초기화면** — 공정도(공정 단계) 기준으로 절차서 링크 제공 + 전체 검색 |
| `list.html` | **목록 페이지** — 공정/종류/검색어로 필터링, 상세로 이동 |
| `detail.html` | **상세 페이지** — 절차서 메타정보 + PDF 뷰어(iframe) + 다운로드 |

## 사용 방법 (최종 사용자)

1. 배포받은 zip 압축을 풉니다.
2. `index.html` 을 더블클릭 → 기본 브라우저(Chrome/Edge)에서 열립니다.
3. 공정도의 단계를 클릭하거나, 상단 검색으로 절차서를 찾습니다.

> 권장 브라우저: 최신 Chrome / Edge

## 절차서 추가·수정 방법 (관리 담당자)

코드를 몰라도 **두 곳만** 손대면 됩니다.

1. **PDF 파일 넣기**: 실제 절차서 PDF 를 `docs/` 폴더에 복사합니다.
2. **목록에 등록**: `assets/js/data.js` 의 `documents` 배열에 항목을 추가합니다.

```js
{
  id: "DOC-MAC-003",          // 문서번호(고유)
  title: "가공 2공정 작업표준",  // 화면에 보일 이름
  step: "p03",                 // 공정 단계 id (processSteps 참고)
  type: "작업표준",            // 절차서 / 작업표준 / 점검표 / 관리계획
  rev: "Rev.1",
  date: "2026-05-01",
  owner: "생산1팀",
  keywords: ["가공", "2공정"],  // 검색용 키워드
  file: "docs/DOC-MAC-003.pdf", // docs/ 안의 실제 파일명과 일치!
},
```

- 공정 단계를 바꾸려면 같은 파일의 `processSteps` 배열을 수정합니다.
- 회사명/제목은 `siteTitle`, `siteSubtitle`, `org` 값으로 변경합니다.

## 디렉터리 구조

```
procedure-site/
├─ index.html        # 공정도 초기화면
├─ list.html         # 목록 페이지
├─ detail.html       # 상세(PDF 뷰어)
├─ assets/
│  ├─ css/style.css
│  └─ js/
│     ├─ data.js     # ← 절차서 데이터 (여기만 수정)
│     └─ app.js      # 화면 로직 (수정 불필요)
└─ docs/             # ← 실제 절차서 PDF 보관
```

## 기술 메모

- 외부 CDN·폰트·라이브러리를 전혀 사용하지 않아 폐쇄망에서 완전 동작합니다.
- 데이터는 `fetch(JSON)` 대신 `data.js`(전역 변수)로 주입 → `file://` 직접 열기에서도 CORS 문제 없음.
- PDF 는 브라우저 내장 뷰어로 표시(변환 없음, 원본 보존).
