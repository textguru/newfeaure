## 5. 화면 흐름도

```
[진입] → 지사선택 → 시험선택(팝업) → 조회 → 목록표시 →
        ├ (결과 있음) → 엑셀 다운로드 가능
        └ (결과 없음) → {{MSG-002}}
```
