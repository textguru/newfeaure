생활기록 통합관리
=================

병원 · 자동차 · 경조사 · 보험/구독 · 가전/보증 등 일상의 지출·수입 기록을
한 곳에서 관리하는 **로컬 단일 파일 애플리케이션**입니다. 설치·빌드·서버가
필요 없습니다.

실행 방법
--------

`index.html` 파일을 웹 브라우저에서 열기만 하면 됩니다. (파일 더블클릭 →
Chrome / Edge / Safari 등에서 열기)

데이터는 브라우저의 `localStorage`에 자동 저장되므로, 같은 브라우저에서
다시 열면 입력한 내용이 그대로 유지됩니다. (인터넷 연결 불필요 · 완전 오프라인)

주요 기능
--------

- **분류별 집계**: 분류별 건수 / 지출 / 수입 합계와 순수입(수입 − 지출) 자동 계산
- **차트**: 분류별 지출 막대 차트, 월별 수입·지출 추이 차트 (외부 라이브러리 없이 Canvas로 직접 그림)
- **기록 관리**: 추가 / 수정 / 삭제
- **검색·필터·정렬**: 키워드 검색, 분류·구분(수입/지출) 필터, 열 머리글 클릭 정렬
- **CSV 내보내기 / 가져오기**: 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM CSV 사용
- **자동 저장**: 모든 변경 사항은 즉시 localStorage에 저장

기록 항목 (열)
-------------

| 열 | 설명 |
|----|------|
| 날짜 | 발생 일자 (YYYY-MM-DD) |
| 분류 | 병원 / 자동차 / 경조사 / 보험·구독 / 가전·보증 등 (직접 추가 가능) |
| 세부항목 | 예: 내과, 엔진오일, 결혼 |
| 대상·상대 | 예: 본인, K5, 김철수(직장동료) |
| 기관·장소 | 예: OO카센터, OO웨딩홀 |
| 내용·메모 | 상세 내용 |
| 금액(원) | 숫자 (천단위 콤마 자동 표시) |
| 수입/지출 | 수입 또는 지출 |
| 다음일정 | 예: 2026-08-10, 55,000km |
| 상태 | 완료 / 사용중 / 임박 등 (직접 추가 가능) |
| 비고 | 추가 메모 |

CSV 형식
--------

첫 행은 위 표의 한글 열 이름을 헤더로 사용합니다. `내보내기`로 만든 파일을
그대로 `가져오기`할 수 있으며, 가져올 때 기존 데이터를 **대체**할지
**추가**할지 선택할 수 있습니다. 엑셀에서 편집한 CSV도 동일한 헤더를 유지하면
가져올 수 있습니다.

최초 실행 시에는 예시 데이터 7건이 들어 있으며, 자유롭게 수정·삭제하면 됩니다.
