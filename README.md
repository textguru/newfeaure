newfeaure
=========

A simple sample Java project built with Maven.

## Requirements

- JDK 17+
- Maven 3.9+

## Build

```bash
mvn clean package
```

## Run

```bash
java -jar target/sample-java-project-1.0.0.jar
```

## Test

```bash
mvn test
```

## Project structure

```
src/
  main/java/com/example/
    App.java          # Application entry point
    Calculator.java   # Basic arithmetic operations
    Greeter.java      # Greeting message builder
  test/java/com/example/
    CalculatorTest.java
    GreeterTest.java
```
